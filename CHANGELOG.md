# Changelog - SIMON TECH Bot v2.1.0

## [2.1.0] - 2026-06-06

### ✨ Added
- **Upgraded Dependencies** - Latest versions of Baileys and Express
- **Enhanced Configuration** - New .env options for better control
- **Better Logging** - Improved console output with color coding
- **Development Mode** - Nodemon support for hot-reload during development
- **API Support** - Added axios for external API calls
- **Timestamp Support** - Moment.js for better time handling

### 🔧 Improved
- Node.js requirement bumped to v20+ (better performance & security)
- npm requirement updated to v9+ (faster dependency resolution)
- Project structure optimized
- Better error handling

### 🐛 Fixed
- Session stability improvements
- Better QR code generation
- Improved Express server handling

### 📦 Dependencies Updated
- `express`: ^4.21.0 (latest stable)
- `@whiskeysockets/baileys`: ^6.7.16 (maintained)
- `qrcode`: ^1.5.3 (latest)
- `axios`: ^1.7.7 (new - API support)
- `dotenv`: ^16.4.5 (new - env management)
- `chalk`: ^5.3.0 (new - colored output)
- `moment`: ^2.29.4 (new - time handling)

### 🚀 Deployment
- Railway support enhanced
- Better environment variable handling
- Improved startup process
